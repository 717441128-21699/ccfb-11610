# 定制拼图生成器(Laser Puzzle Studio)

文创店定制拼图的一站式生成工具:顾客上传照片,程序自动生成每块形状都不同的
切割线(随机凸起/凹口 + 小猫/星星异形块,自动避开人脸),三维预览可拖拽试拼,
一键导出激光切割路径(SVG / DXF)。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建
npm test         # 几何 / 路径优化 / 性能单元测试
```

浏览器打开 dev 服务器地址即可使用,无需后端。

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 画面分成几百块,凸起/凹口随机 | 网格 + 每条边独立随机参数(颈宽/头宽/高度/偏斜/朝向)的 Catmull-Rom 榫卯曲线,种子可复现 |
| 异形块(小猫/星星) | 极坐标剪影(圆头+耳凸包 / 五角余弦波),经角点对齐形变嵌入格子,与邻块共享边界 |
| 切线不能太尖 | 全部切线做最小曲率半径约束(默认 1.0 mm,可调),拉普拉斯松弛迭代保证,UI 显示实测最小圆角 |
| 人脸不被异形块切碎 | FaceDetector API(有则用)+ 肤色连通域启发式兜底,自动检测;异形块只落在远离人脸的格子;支持手动增删人脸框 |
| 共边只切一次 | 边按邻接关系只生成一次,拼图块引用同一条边 |
| 空走尽量短 | 贪心最近邻排序 + 2-opt 改进(可选方向),UI 显示优化前后空走对比 |
| 三维预览 | WebGL2:挤出成片、照片贴图、整版/散开/爆炸视图 |
| 拖拽拼回 + 吸附 | GPU 颜色拾取选中碎块,平面拖动,Q/E 旋转,靠近正确位置高亮并在松手时吸附锁定 |
| 500 块 ≤ 10 秒 | 实测生成 + 路径优化约 0.3–0.5 秒(单元测试中有 10 秒断言) |

## 操作说明

- **左侧面板**:上传照片 → 自动检测人脸(可在缩略图上拖框添加、点击删除)→
  调参数(块数/板宽/最小圆角/异形块数量/种子/板厚)→ 生成拼图。
- **三维视图**:拖动旋转视角,滚轮缩放,右键平移;点击碎块拖动,Q/E 旋转
  (Shift 微调),靠近正确位置会高亮,松手自动吸附;"打散"重新洗牌,
  "一键拼好"全部归位,"爆炸视图"沿高度散开观察切面。
- **导出**:SVG(LightBurn 等直接导入)和 DXF(LWPOLYLINE,CUT 图层,
  毫米单位,Y 轴已翻转为 CAD 向上)。切割顺序已按空走最短排好。

## 代码结构

```
src/
  geom/curve.ts        向量、Catmull-Rom、曲率半径、最小半径松弛、圆角多边形
  geom/triangulate.ts  耳切法三角剖分
  puzzle/generator.ts  网格、随机榫卯边、异形块放置(避人脸)、轮廓装配
  puzzle/silhouettes.ts 猫/星剪影(极坐标定义 + 半径约束平滑)
  puzzle/faces.ts      人脸检测(FaceDetector + 肤色启发式)
  laser/optimize.ts    切割路径排序(贪心 + 2-opt)
  laser/export.ts      SVG / DXF 导出
  gl/mat4.ts           矩阵库
  gl/renderer.ts       WebGL2 渲染器(挤出网格、轨道相机、GPU 拾取)
  app.ts               UI 状态、交互、动画
test/puzzle.test.ts    12 个单元测试(几何不变量、避让、性能)
```

## 激光加工说明

- 导出路径单位为毫米,切割顺序即文件中的路径顺序(已优化空走)。
- 共边只切一次,切缝自然产生轻微松动,一般无需补偿;若需紧配合,
  可在激光软件中对全部路径统一做一半切缝宽的外扩。
- "最小圆角"参数对应木材不烧糊的安全曲率半径,胶合板建议 ≥ 0.8 mm。
